# Bitstream

Put the FPGA bitstream for the RP2040 here as `mac_shrike.bin`.

It is generated by Go Configure Software Hub: copy
`<your Go Configure project>/ffpga/build/bitstream/FPGA_bitstream_MCU.bin`
here and rename it to `mac_shrike.bin`. Do not use `FPGA_bitstream_FLASH_MEM.bin`.

Built with Go Configure v6.56 for SLG47910V (Rev BB):
362 / 1120 LUT5, 163 FFs, 64 / 140 CLBs, 68.6 MHz achievable (50 MHz used).
Tested on a Shrike Lite board: `main.py` prints `RESULT: PASS`.
